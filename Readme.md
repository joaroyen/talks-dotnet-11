# .NET 11 er her

.NET 11 tar nye steg for å gjøre .NET til en universell plattform for utviklere. Ikke noe revolusjonerende men like vel viktige utvidelser for å henge med i nye standarder og trender for programvareutvikling. Både rammeverk, kjøremiljø og verktøy har fått forbedringer som er nyttige for oss.

Vi går gjennom høydepunktene og fremhever noen utvalgte favoritter:

- Avansert serialisering
- Asynkron validering
- Verktøytips både for oss og agenter
